# 세계 아틀라스 운영 기준

세계 아틀라스는 레벨 이름 목록이 아니라 이 프로젝트의 실제 설정 위키다. 실제 이미지가 없어도 각 장소가 무엇인지, 어떤 구조와 환경 법칙을 가지는지, 무엇이 위험하고 어디에서 들어오고 나가는지까지 읽을 수 있어야 한다. 단일 원본 데이터는 `public/world/atlas.json`이며, `atlas.html`과 Google Docs의 `WORLD ATLAS` 탭은 이 내용을 사람이 읽기 좋은 형태로 보여준다.

## 문서 역할 분리

| 문서 | 용도 | 넣지 않는 것 |
| --- | --- | --- |
| `WORLD BIBLE` | 모든 레벨에 공통으로 적용되는 캐논, 제작 법칙, 이미지·경로·검수 파이프라인 | 레벨별 긴 설정 본문 |
| `WORLD ATLAS` | Level 0–5와 세부레벨의 위키 문서. 구조, 현상, 위험, 지역, 입구·출구와 미확정 설정 | 일별 작업 내역과 실행 로그 |
| 제작 로그 | 생성·검수·배포 결과와 다음 실행 단위 | 캐논의 최종 설명 |

이 셋을 섞지 않는다. 세계관을 읽으려면 `WORLD ATLAS`, 제작 규칙을 확인하려면 `WORLD BIBLE`, 무엇을 했는지 추적하려면 제작 로그를 본다.

## 위키 항목 필수 구조

모든 레벨과 세부레벨은 다음 내용을 가진다.

1. 개요와 핵심 정체성
2. 세계 안에서의 역할
3. 공간 구조와 공간 DNA
4. 환경 법칙
5. 고정된 현상과 실제 위험
6. 내부 지역
7. 입구와 출구
8. 연결 후보
9. 드리프트 금지
10. 아직 확정하지 않은 질문과 제작 상태

이 구조가 채워지지 않으면 이름이 있어도 아틀라스 항목으로 완성된 것이 아니다. 데이터 검증기가 필수 필드를 검사한다.

## 대표 이미지와 판독 정보

각 항목은 목록 장식이 아니라 공간을 읽기 위한 대표 이미지를 한 장 가진다. 이미지 바로 옆에는 분류표를 두고 규모, 이동성, 환경 압력, 주요 위험, 지역·연결·미확정 질문 수를 함께 보여준다. 본문은 다음 세 층으로 읽힌다.

- `observed`: 승인된 플레이 장면에서 가져온 관찰 이미지. 현재 Level 0만 해당한다.
- `concept`: 재질, 규모, 조명과 분위기를 설명하는 아틀라스 전용 개념 이미지. 플레이 장면도, 최종 지형도 아니다.
- 감각 프로필과 경험 곡선: 빛·소리·공기를 요약하고 도착·심화·경계의 순서로 공간 경험을 설명한다.

플레이 장면 이미지 제작은 현재 `productionFocus`로 지정한 Level 0.1 파일럿에만 재개한다. 다른 레벨의 신규 이미지는 계속 중지한다. 아틀라스 개념 이미지는 위키 판독용 자료이므로 클릭 경로, 장면 ID, 실제 연결 또는 제작 완료를 뜻하지 않는다. 이미지 생성 기록과 재현용 브리프는 `docs/atlas-image-prompts-ko.md`와 `docs/generation-prompts.md`에 남긴다.

## 제작 사양 계층

설정 뼈대가 실제 장면 제작 직전 단계에 도달하면 해당 항목에 `productionSpec`을 추가한다. 이 필드는 제작 시작이나 플레이 가능 상태를 뜻하지 않는다. 이미지가 없어도 다음 제작자가 같은 목표와 검수 기준으로 파일럿을 만들 수 있을 만큼 구체화됐다는 뜻이다.

1. 파일럿 목표와 장면 수
2. 순서가 고정된 장면 비트
3. 네 종류 이상 여섯 종류 이하의 대표 공간
4. 공간이 달라질 수 있는 변형 축과 각 축의 상한
5. 카메라 문법과 이미지 프롬프트 규칙
6. 사람이 이미지를 본 뒤 통로를 등록하는 경로 정책
7. 앞 장면과 갈래별 독립 구조를 보존하는 연속성 규칙
8. 파일럿 전체의 검수 통과 기준

`productionFocus`는 한 번에 하나의 레벨과 진입 경계만 가리킨다. 현재 초점은 `LV-000.1`, 진입 경계는 `CON-L0-L01-ENTRY`, 파일럿은 5장이다. 단계는 `pilot-in-production`이다. `L01-0001`은 사람 통로 마스크 검수를 마쳤고, 공개 승격을 보류한 채 그 내부 최전선에서 두 번째 후보 `L01-0002`를 생성해 통로 검수를 기다린다.

## Level 0.1 첫 제작 계약

다섯 장은 `Transition Clamp → Service Bend → Atrium Edge → Habitation Ring → Vertical Transfer Split`의 순서로 공간의 규모를 연다. 첫 장에서는 Level 0의 누런 벽지와 카펫이 금속 프레임·복합 보행면에 직접 맞물려야 한다. 두 번째 장까지 Level 0 잔재를 물리적으로 남기고, 세 번째 장부터는 중앙 공동을 난간·반사·원거리 조명으로만 암시한다. 공동의 완전한 전경은 파일럿에서 금지한다.

통로 수는 프롬프트의 목표일 뿐 확정값이 아니다. 기본 목표는 1–2개, 3개는 파일럿 전체에서 최대 한 장, 4개 이상은 재생성하거나 별도의 희귀 승인을 받기 전까지 보류한다. 실제 등록 수는 이미지 생성 후 사람이 모든 보행 가능한 개구부를 점으로 확인한 결과를 따른다. 유리 너머 공간, 난간 밖 공동, 반사와 접근 불가능한 상하층에는 클릭 마스크를 만들지 않는다.

첫 진입 경계는 실제 장면 `L0-0009A`의 경로 `L0-0009A-P1`에 묶인다. 원본의 카메라 높이 1.65m, 40mm 환산 렌즈, `전진 후 오른쪽` 진행 방향을 출발 스냅샷으로 고정한다. 예정 도착 장면 `L01-0001`과 후속 `L01-0002`는 후보 그래프 안에서만 연결되며 플레이 장면 레지스트리에는 아직 추가하지 않는다. 검수 완료 후보에는 안정적인 내부 경로 ID를 붙여 다음 후보를 만들 수 있지만, 최종 이미지, 나란히 연속성 검수, 사람 마스크, 모바일 클릭, 저장·복원 테스트와 5장 전체 승인이 끝날 때까지 현재 콘텐츠 경계 동작을 유지한다.

## 계층

| 계층 | 역할 | 예시 ID | 플레이어 공개 |
| --- | --- | --- | --- |
| 레벨 | 독립적인 핵심 정체성과 공간 법칙을 가진 거대한 환경 | `LV-004` | 표시하지 않음 |
| 세부레벨 | 부모 레벨 안에 있으나 자체 공간 DNA와 진입·이탈 문법을 가진 대규모 환경 | `LV-004.1` | 표시하지 않음 |
| 내부 지역 | 같은 레벨 법칙 안에서 반복 발견된 공간 문법을 관리하는 라벨 | `REG-L4-GRID` | 표시하지 않음 |
| 장면 | 한 장의 승인된 실제 이미지와 클릭 경로 | `L0-0009A` | 이미지 자체만 보임 |
| 경계 | 특정 장면의 특정 통로에 고정되는 단방향 레벨 전환 | `CON-L0-L01-ENTRY` | 공간으로만 보임 |

내부 지역은 레벨처럼 별개의 세계가 아니다. Level 0의 `Entry Halls`, `Offset Passages`, `Open Floor`는 생성 프롬프트를 고정하는 테마 구역이 아니라, 실제로 관찰되거나 앞으로 검증할 공간 문법을 찾기 위한 비공개 관리 라벨이다.

## 원전 처리

- `reinterpretation`: 공식 위키의 상징적 명칭 또는 핵심 공간 인상을 가져오되 내부 구조, 연결, 위험과 사건은 새로 만든다.
- `original`: 명칭과 공간 법칙 모두 이 프로젝트에서 만든다.
- `hybrid`: 이미 제작 중인 독자 구조에 공식 명칭의 일부만 결합한다.

조직, 엔티티, 사건, 원문 문장과 공식 연결 관계는 자동으로 가져오지 않는다. 참고한 공식 페이지는 각 항목의 `sourceUrls`에 남긴다.

## 제작 상태

- `in-production`: 실제 장면 그래프가 있거나 사람 검수 대기 파일럿이 존재하는 레벨. 현재는 `LV-000`과 `LV-000.1`이 해당한다.
- `skeleton`: 핵심 정체성과 공간 DNA가 있지만 아직 실제 장면을 만들지 않은 항목.
- `concept`: 방향 후보. 다른 항목과 비교·수정 후 뼈대로 승격한다.
- `observed`: 실제 장면에서 이미 반복 확인한 내부 지역.
- `planned`: 다음 제작 전에 검증할 내부 지역.
- `reserved`: 실제 장면의 통로를 미래 경계 후보로 예약했지만 아직 연결하지 않은 상태.

`concept`, `skeleton`, `reserved`는 모두 플레이 불가능하다. 파일럿 후보가 생기면 레벨은 `in-production`으로 바꿀 수 있지만, 후보 검수와 경계 게이트를 통과하기 전에는 활성 연결로 바꾸지 않는다.

## 첫 아틀라스 범위

### 부모 레벨

1. Level 0 — Threshold: 현재 제작 중인 황색 상업·업무 후면 공간.
2. Level 1 — Habitable Zone: 운영 직전처럼 보이나 한 번도 사용되지 않은 콘크리트 물류층.
3. Level 2 — Abandoned Utility Halls: 열, 배관과 압력이 동선을 다시 만드는 설비 복도.
4. Level 3 — Electrical Station: 에너지는 흐르지만 결과가 없는 스위치기어·케이블 환경.
5. Level 4 — Abandoned Office: 조직과 시간이 제거된 청회색 사무·회의 층.
6. Level 5 — Terror Hotel: 환대가 영원히 준비 중인 빛바랜 호텔.

### 세부레벨

1. Level 0.1 — Zenith Station: Level 0 안에 끼어든 금속·유리 환형 거대구조 재해석.
2. Level 0.2 — Remodeled Mess: 완성과 해체가 같은 방에서 충돌하는 개보수 과도기 재해석.
3. Level 1.1 — Night Shift: 교대 직전 상태에 멈춘 독자 물류·사무 구역.
4. Level 2.1 — Pressure Annex: 보이지 않는 압력이 방의 크기 감각을 바꾸는 독자 격실.
5. Level 3.1 — Relay Floors: 낮은 릴레이 갤러리와 이중 바닥이 포개지는 독자 구조.
6. Level 4.1 — Records Annex: 사실을 전달하지 않는 기록이 과잉 저장된 독자 부속동.
7. Level 5.1 — Service Floors: 환대를 유지할 노동만 사라진 호텔 후면 기능층.

## 경계 설계 원칙

1. 모든 레벨 연결은 단방향이며 특정 장면의 특정 통로에 고정한다.
2. 아틀라스의 연결 후보는 세계 지도를 계획하기 위한 문서이며 실제 장면 연결이 아니다.
3. 경계는 `concept → reserved → active` 순서로 승격하지만, 현재 데이터는 `active`를 허용하지 않는다.
4. Level 0의 첫 예약 경계는 `L0-0009A-P1 → LV-000.1`이다. 이미지 제작을 재개하기 전까지 기존 콘텐츠 경계 동작을 유지한다.
5. 부모 레벨과 세부레벨은 가까운 관계이므로 보행 가능한 구조 경계나 여러 장면의 점진 변화가 우선이다.
6. 서로 다른 부모 레벨은 문, 서비스 구획, 수직 이동처럼 공간 안에서 읽히는 명확한 경계를 사용한다.

## 다음 문서 작업

이미지를 만들기 전에 각 뼈대 항목을 한 번씩 검토한다. 검토 순서는 `핵심 정체성 → 세계 안에서의 역할 → 공간 구조 → 환경 법칙 → 현상·위험 → 내부 지역 → 입구·출구 → 금지 요소 → 미확정 질문`이다. 이 과정에서 유사한 레벨은 합치고, 부모 레벨의 변형으로 충분한 항목은 세부레벨이나 내부 지역으로 내린다.
