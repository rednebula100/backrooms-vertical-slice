# 세계 아틀라스 운영 기준

세계 아틀라스는 플레이 화면이 아니라 제작용 위키다. 실제 이미지가 없어도 레벨의 정체성, 세부레벨의 범위, 내부 지역의 반복 문법과 희귀 경계 후보를 먼저 합의할 수 있게 한다. 단일 원본 데이터는 `public/world/atlas.json`이며, `atlas.html`은 이 데이터를 읽어 보여준다.

## 계층

| 계층 | 역할 | 예시 ID | 플레이어 공개 |
| --- | --- | --- | --- |
| 레벨 | 독립적인 핵심 정체성과 공간 법칙을 가진 거대한 환경 | `LV-004` | 표시하지 않음 |
| 세부레벨 | 부모 레벨 안에 있으나 자체 공간 DNA와 진입·이탈 문법을 가진 대규모 환경 | `LV-004.1` | 표시하지 않음 |
| 내부 지역 | 같은 레벨 법칙 안에서 반복 발견된 공간 문법을 관리하는 라벨 | `REG-L4-GRID` | 표시하지 않음 |
| 장면 | 한 장의 승인된 실제 이미지와 클릭 경로 | `L0-0009A` | 이미지 자체만 보임 |
| 경계 | 특정 장면의 특정 통로에 고정되는 단방향 레벨 전환 | `CON-L0-L01-ENTRY` | 공간으로만 보임 |

내부 지역은 레벨처럼 별개의 세계가 아니다. Level 0의 `Entry Halls`, `Offset Passages`, `Open Floor`는 생성 프롬프트를 고정하는 테마 구역이 아니라, 실제로 관찰되거나 앞으로 검증할 공간 문법을 찾기 위한 비공개 관리 라벨이다.

## 원전 처리

- `reinterpretation`: 공식 위키의 상징적 명칭 또는 핵심 공간 인상을 가져오되 내부 구조, 연결, 위험과 사건은 새로 만든다.
- `original`: 명칭과 공간 법칙 모두 이 프로젝트에서 만든다.
- `hybrid`: 이미 제작 중인 독자 구조에 공식 명칭의 일부만 결합한다.

조직, 엔티티, 사건, 원문 문장과 공식 연결 관계는 자동으로 가져오지 않는다. 참고한 공식 페이지는 각 항목의 `sourceUrls`에 남긴다.

## 제작 상태

- `in-production`: 실제 장면 그래프가 존재하는 레벨. 현재는 `LV-000`만 해당한다.
- `skeleton`: 핵심 정체성과 공간 DNA가 있지만 아직 실제 장면을 만들지 않은 항목.
- `concept`: 방향 후보. 다른 항목과 비교·수정 후 뼈대로 승격한다.
- `observed`: 실제 장면에서 이미 반복 확인한 내부 지역.
- `planned`: 다음 제작 전에 검증할 내부 지역.
- `reserved`: 실제 장면의 통로를 미래 경계 후보로 예약했지만 아직 연결하지 않은 상태.

`concept`, `skeleton`, `reserved`는 모두 플레이 불가능하다. 이미지 생성 일시 중지 기간에는 새 항목을 `in-production`이나 활성 연결로 바꾸지 않는다.

## 첫 아틀라스 범위

### 부모 레벨

1. Level 0 — Threshold: 현재 제작 중인 황색 상업·업무 후면 공간.
2. Level 1 — Habitable Zone: 운영 직전처럼 보이나 한 번도 사용되지 않은 콘크리트 물류층.
3. Level 2 — Abandoned Utility Halls: 열, 배관과 압력이 동선을 다시 만드는 설비 복도.
4. Level 3 — Electrical Station: 에너지는 흐르지만 결과가 없는 스위치기어·케이블 환경.
5. Level 4 — Abandoned Office: 조직과 시간이 제거된 청회색 사무·회의 층.
6. Level 5 — Terror Hotel: 환대가 영원히 준비 중인 빛바랜 호텔.

### 세부레벨

1. Level 0.1 — Zenith Station: Level 0 안에 끼어든 금속·유리 환형 거대구조 재해석.
2. Level 0.2 — Remodeled Mess: 완성과 해체가 같은 방에서 충돌하는 개보수 과도기 재해석.
3. Level 1.1 — Night Shift: 교대 직전 상태에 멈춘 독자 물류·사무 구역.
4. Level 2.1 — Pressure Annex: 보이지 않는 압력이 방의 크기 감각을 바꾸는 독자 격실.
5. Level 3.1 — Relay Floors: 낮은 릴레이 갤러리와 이중 바닥이 포개지는 독자 구조.
6. Level 4.1 — Records Annex: 사실을 전달하지 않는 기록이 과잉 저장된 독자 부속동.
7. Level 5.1 — Service Floors: 환대를 유지할 노동만 사라진 호텔 후면 기능층.

## 경계 설계 원칙

1. 모든 레벨 연결은 단방향이며 특정 장면의 특정 통로에 고정한다.
2. 아틀라스의 연결 후보는 세계 지도를 계획하기 위한 문서이며 실제 장면 연결이 아니다.
3. 경계는 `concept → reserved → active` 순서로 승격하지만, 현재 데이터는 `active`를 허용하지 않는다.
4. Level 0의 첫 예약 경계는 `L0-0009A-P1 → LV-000.1`이다. 이미지 제작을 재개하기 전까지 기존 콘텐츠 경계 동작을 유지한다.
5. 부모 레벨과 세부레벨은 가까운 관계이므로 보행 가능한 구조 경계나 여러 장면의 점진 변화가 우선이다.
6. 서로 다른 부모 레벨은 문, 서비스 구획, 수직 이동처럼 공간 안에서 읽히는 명확한 경계를 사용한다.

## 다음 문서 작업

이미지를 만들기 전에 각 뼈대 항목을 한 번씩 검토한다. 검토 순서는 `핵심 정체성 → 공간 DNA → 금지 요소 → 내부 지역 → 진입 경계 → 이탈 경계 → 감정 범위`다. 이 과정에서 유사한 레벨은 합치고, 부모 레벨의 변형으로 충분한 항목은 세부레벨이나 내부 지역으로 내린다.
