# Project rules

- This is an image-first Backrooms exploration project. `docs/world-bible-ko.md` is the source of truth.
- Use the installed `$imagegen` skill for raster scene generation. Never substitute SVG, HTML, CSS, canvas art, wireframes, or placeholders for requested raster scenes.
- Invisible SVG or coordinate overlays are allowed only as input regions over approved raster images.
- Approved scenes form a fixed, non-random world. Gameplay never generates images at runtime.
- Preserve working code before considering replacement. Keep scene IDs and asset names stable.
- Do not add visible game UI unless explicitly requested.
- Do not add reverse movement, runtime randomness, branch merging, unrelated systems, entities, or world expansion without approval.
